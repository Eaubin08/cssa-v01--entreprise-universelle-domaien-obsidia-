# CSSA — Mémoire & Identité

Status: SEPARATE_PROJECT / NOT_ADMINISTRATION

This project preserves the separate CSSA idea around:
- club memory;
- local identity;
- youth/educational transmission;
- archives;
- interviews;
- culture/supporters/volunteers;
- short-form content;
- potential living exhibition / mini-museum concepts.

It may later become another CSSA project or domain-facing pack, but it must not contaminate the Administration domain merely because both belong to the same organization.

Shared organization identity is allowed.
Shared business semantics are not assumed.
