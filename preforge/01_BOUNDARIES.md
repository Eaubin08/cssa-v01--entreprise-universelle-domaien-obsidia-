# 01 — BOUNDARIES

## Layer ownership

### Universal / UDIP
Owns only cross-domain integration contracts and invariants.

Candidate surfaces:
- domain identity;
- object references/mapping;
- provenance;
- unknowns;
- contradictions;
- risk/evidence references;
- canonical governance payload;
- decision/permission/execution separation;
- receipt/proof/replay references;
- conformance rules.

### Administration
Owns reusable administrative semantics only after evidence.

Candidate objects:
- dossier;
- document;
- correspondence;
- request;
- obligation;
- deadline;
- responsible role;
- approval;
- procedure;
- processing state;
- administrative anomaly;
- evidence/trace.

These are candidates, not yet frozen universal truths.

### CSSA
Owns club-specific reality:
- match;
- team;
- referee;
- official;
- licence;
- FFF/LGEF interactions;
- Footclubs/FMI;
- match-day protocol;
- competition-specific deadlines;
- club-specific roles, habits and local workflows.

## Non-negotiable boundaries

```text
DOMAIN != AUTHORITY
SOURCE != TRUST
OBSERVATION != TRUTH
PROPOSAL != DECISION
DECISION != ACTION
CAPABILITY != PERMISSION
MEMORY != COGNITION
DATA != EXPERIENCE != LEARNING != KNOWLEDGE != MEMORY
```

No lower layer may silently redefine an upper-layer contract.
No upper layer may absorb CSSA meaning merely for convenience.
