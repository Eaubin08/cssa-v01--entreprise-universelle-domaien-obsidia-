# 10 — DEFINITION OF DONE

## Pre-forge done when

- main and relevant historical branches have semantic verdicts;
- public CSSA/FFF/LGEF source map exists;
- layer boundaries are frozen for V0;
- no CSSA-specific semantic has leaked upward without evidence;
- authority matrix is explicit;
- test matrix covers normal, unknown, contradiction, stale, duplicate and human-gray cases;
- build order is accepted;
- claim boundaries are written.

## Administration V0 done when

- at least one real audited administrative workflow is represented end-to-end;
- unknowns/contradictions/provenance survive translation;
- no parallel authority exists;
- readonly path is replayable;
- domain conformance tests pass.

## CSSA V0 done when

- real CSSA-specific objects/rules/workflows map without kernel mutation;
- at least one match-related administrative lifecycle is demonstrated;
- human checkpoints are explicit;
- receipts/replay exist for tested paths.

## V0.1 adaptability evidence

CSSA alone is not sufficient.

The stronger claim becomes available only when another organization can be connected primarily by supplying new organization/domain semantics rather than rebuilding Universal/Core.
