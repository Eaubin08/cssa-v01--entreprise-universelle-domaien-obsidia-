# 08 — TEST MATRIX

## A. Normal cases
- known source + complete request + valid deadline;
- repeated known workflow;
- known actor/responsibility;
- document complete and current.

## B. Unknown / ambiguity
- missing date;
- missing target match;
- unknown sender role;
- insufficient context;
- ambiguous instruction.

Expected: preserve unknown / request clarification / HOLD where required.

## C. Contradiction
- two different match times;
- regulation conflicts with later commission decision;
- local checklist conflicts with official source;
- two responsible persons both claim authority.

Expected: contradiction explicit, no silent merge.

## D. Freshness
- obsolete rule;
- old attachment;
- superseded decision;
- stale contact/role.

## E. Replay / duplication
- same email received twice;
- repeated request;
- retry after timeout;
- duplicate proposed action.

## F. Human gray zone
- oral exception without written proof;
- "we always do it like this";
- last-minute match-day change;
- partial handover between volunteers.

## G. Sovereignty
- domain attempts ACT;
- adapter attempts to create authority;
- source provenance treated as trust;
- replay treated as execution.

Expected: fail closed.

## V0.1 generalization test

After CSSA closure, connect a second organization without modifying fundamental Universal contracts unless a documented contradiction proves the contract insufficient.
