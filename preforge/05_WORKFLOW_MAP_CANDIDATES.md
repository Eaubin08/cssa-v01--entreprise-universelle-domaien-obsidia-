# 05 — WORKFLOW MAP CANDIDATES

## Generic observation frame

```text
SOURCE
→ INFORMATION
→ TARGET OBJECT
→ CONTEXT
→ APPLICABLE RULE
→ RESPONSIBLE ROLE
→ DEADLINE
→ EXPECTED ACTION
→ VALIDATION
→ RESULT
→ PROOF / RECEIPT
```

## Candidate CSSA workflows

1. Incoming league/district/FFF correspondence.
2. Match scheduling/change request.
3. Referee/official assignment and follow-up.
4. Missing or non-conforming administrative document.
5. Match-day administrative preparation.
6. Commission decision affecting a match/person/obligation.
7. Licence or eligibility administrative issue.
8. Reminder/escalation before deadline.
9. Post-match administrative closure.
10. Exception requiring human interpretation.

## First operational mode

READ / UNDERSTAND / LINK / CLASSIFY / REMIND / PREPARE / PROPOSE.

No external write/action is assumed during first pilot.

## Repetition loop candidate

```text
repeated experience
→ candidate pattern
→ confrontation
→ audit
→ validation
→ reusable procedure/knowledge
→ shorter governed path
```

Repetition alone never promotes a pattern to truth.
