# 06 — RISK AND GRAY ZONES

The administrative domain is valuable specifically because it contains imperfect human reality.

## Target gray zones

- incomplete email;
- implicit request;
- contradictory instructions;
- old rule vs newer decision;
- oral exception;
- late change;
- missing document;
- duplicate request;
- wrong recipient;
- unclear responsibility;
- deadline ambiguity;
- informal workaround;
- document present but obsolete;
- rule valid generally but overridden in a specific case;
- action performed without trace;
- human memory conflicting with written source.

## Required system behavior

For each gray zone:
- preserve ambiguity;
- preserve provenance;
- expose unknowns;
- distinguish contradiction from risk;
- refuse silent completion;
- identify required human decision;
- produce HOLD/BLOCK where governance requires it;
- keep a replayable trace.

## Specific anti-pattern

Never infer:
```text
"they always do it this way"
= "this is the correct rule"
```
