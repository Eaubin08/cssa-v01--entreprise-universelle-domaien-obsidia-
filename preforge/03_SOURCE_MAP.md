## Source status rule

Every source must preserve at minimum:
- origin;
- date/freshness when available;
- scope;
- authority level;
- confidence/unknown status;
- whether it is public, internal, observed, inferred or validated.

Public regulation != actual local practice.
Actual local practice != valid rule.
Repeated behavior != canon.
