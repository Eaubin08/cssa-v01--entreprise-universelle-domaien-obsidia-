# CSSA — REPORTING CALENDAR V0

## Weekly — Monday

Recipients/views:
- Manager Général
- Administration
- Secrétariat
- Finance/Admin Accounting
- Direction Technique
- Formation / Foot 5-8
- Team Managers / Intendance
- Matchday / Security / Volunteers
- Ticketing
- Partnerships
- Communication

Core question:
**What must happen this week, what is blocked, and who needs the information?**

## Every two weeks — Monday

Recipients/views:
- Direction/Présidence
- Manager Général
- Administration
- Secrétariat
- Finance
- Technique/Academy
- Matchday
- Ticketing
- Partnerships
- Communication
- School/education where relevant

Core question:
**Where are dependencies drifting across layers, and what requires an organizational decision?**

## Monthly — day 1

Recipients/views:
- Direction/Présidence
- Manager Général
- Administration
- Finance
- Partnerships
- School/education where relevant

Core question:
**What changed in the organization, where are money/capacity/risk moving, and what must be decided for the next month?**

## Event priority

```text
PRE_RUNTIME_BLOCK  → sensitive/privacy stop
BLOCK              → contradiction / cannot proceed
HOLD               → missing facts / authority / proof
ALLOW              → internally reportable/processable
```

ALLOW does not mean an external action is authorized.

## Report truth legend

```text
PUBLIC_CONFIRMED
SECONDARY_CORROBORATED
ESTIMATED
SIMULATED_NOT_OBSERVED
REAL_FIELD_EVIDENCE
UNKNOWN_PRIVATE
```

Each item keeps its class all the way to the persona view.
