# CSSA READONLY PILOT V0

Status: PREPARED / NOT AUTHORIZED / NOT DEPLOYED

## Pilot scope

First useful mode:

```text
READ
CLASSIFY
LINK
DETECT DEADLINE
DETECT MISSING INFORMATION
DETECT CONTRADICTION
PREPARE CHECKLIST
PREPARE DRAFT
PROPOSE
REQUEST HUMAN VALIDATION
RECEIPT
```

Not enabled:

```text
SEND EMAIL
MODIFY FOOTCLUBS
SUBMIT FMI
CHANGE MATCH
DECLARE LICENCE
FINANCIAL COMMITMENT
SIGN
AUTONOMOUS EXTERNAL ACTION
```

## First dashboard candidates

- today / next 7 days deadlines;
- match-related open administrative cases;
- waiting for other club;
- waiting for LGEF/District decision;
- missing document/information;
- unresolved contradiction;
- action prepared but awaiting human validation;
- completed cases with proof.

## First measurable outcome

Do not measure 'AI intelligence'. Measure:
- deadline misses detected/prevented;
- time to find the right case/document;
- duplicate work reduced;
- unresolved cases surfaced;
- proportion of cases with complete trace;
- number of human clarifications requested because uncertainty was preserved.

## Deployment constraint

Pilot is internal/read-only until a separate authorization document explicitly changes an action boundary.
